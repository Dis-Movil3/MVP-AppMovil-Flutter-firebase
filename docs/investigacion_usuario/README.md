# Investigación de Usuario

---

## 1. Propósito

Esta carpeta contiene la documentación correspondiente a la fase de Investigación de Usuario del proyecto de desarrollo de la aplicación móvil multiplataforma.

Esta etapa tiene como propósito comprender las necesidades, expectativas, dificultades y comportamientos de los usuarios frente al acceso a servicios mediante dispositivos móviles, especialmente en situaciones donde se presentan problemas de experiencia de usuario, tiempos elevados de carga y ausencia de notificaciones en tiempo real.

La investigación constituye el punto de partida para definir las funcionalidades y características que serán incorporadas en el Producto Mínimo Viable (MVP).

---

## 2. Relación con Lean Mobile Development

El proyecto utiliza la metodología Lean Mobile Development, por lo que la investigación de usuario representa la primera etapa del ciclo:

### Investigar → Diseñar → Construir → Medir → Aprender → Mejorar.

Los resultados obtenidos durante esta fase serán utilizados para priorizar las funcionalidades del MVP y evitar el desarrollo de características que no aporten valor al usuario.

---

## 3. Problemática analizada

Los usuarios experimentan altas tasas de abandono al intentar acceder al servicio desde navegadores móviles debido a:

• Interfaces no optimizadas para dispositivos móviles.
• Tiempos de carga superiores a 8 segundos en redes 4G/5G.
• Ausencia de notificaciones push en tiempo real.
• Dificultades durante la navegación.
• Experiencia de usuario poco eficiente.

---

## 4. Objetivo de la investigación
Identificar las principales necesidades, dificultades y expectativas de los usuarios al utilizar servicios desde dispositivos móviles, con el propósito de establecer los requerimientos necesarios para diseñar y desarrollar un MVP que proporcione una experiencia más rápida, sencilla y eficiente.

---

## 5. Documentos de la investigación
### Perfil de usuario
El archivo `perfil_usuario.md` describe las características generales del usuario objetivo, sus necesidades, comportamientos y principales dificultades.

### Necesidades del usuario
El archivo `necesidades_usuario.md` presenta las necesidades identificadas y su relación con la solución propuesta.

### Requerimientos
El archivo `requerimientos.md` transforma las necesidades identificadas en requerimientos funcionales y no funcionales que orientarán el diseño y desarrollo del MVP.

---

## 6. Resultado esperado
Al finalizar esta etapa se espera contar con una definición clara del usuario objetivo y de las necesidades prioritarias que deberán ser atendidas por el MVP.

Los resultados servirán como insumo para la siguiente etapa:

### Investigación de Usuario → Diseño UX/UI.
