# Diseño UX/UI

---

## 1. Descripción

Esta carpeta contiene la documentación correspondiente a la etapa de Diseño de Experiencia de Usuario (UX) e Interfaz de Usuario (UI) del proyecto de aplicación móvil multiplataforma.

El diseño se desarrolla a partir de los resultados obtenidos durante la investigación de usuarios y de los requerimientos definidos para el Producto Mínimo Viable (MVP).

El objetivo principal es diseñar una experiencia móvil sencilla, rápida, intuitiva y adaptada a dispositivos Android, que permita solucionar las principales dificultades identificadas en la problemática inicial.

---

## 2. Relación con Lean Mobile Development

El diseño UX/UI forma parte de la segunda etapa del proceso metodológico:

### Investigar → Diseñar → Construir → Medir → Aprender → Mejorar.

Los resultados de la investigación de usuarios se convierten en decisiones concretas de diseño que serán implementadas inicialmente en el MVP.

El diseño no se considera definitivo desde el comienzo. De acuerdo con el enfoque Lean Mobile Development, podrá modificarse posteriormente a partir de la retroalimentación obtenida durante las pruebas con usuarios reales.

---

## 3. Objetivo del diseño UX/UI

Diseñar una interfaz móvil centrada en las necesidades del usuario, que facilite la navegación, reduzca la cantidad de pasos necesarios para completar las tareas principales y proporcione una experiencia consistente en dispositivos Android.

---

## 4. Principios de diseño

El diseño de la aplicación se basará en los siguientes principios:

## 4.1. Simplicidad

La interfaz deberá presentar únicamente la información y las opciones necesarias para que el usuario pueda realizar sus tareas sin confusión.

## 4.2. Claridad

Los textos, botones, iconos y elementos visuales deberán ser fácilmente identificables y comprensibles.

## 4.3. Consistencia

Los componentes visuales y patrones de navegación deberán mantener un comportamiento consistente en las diferentes pantallas.

## 4.4. Accesibilidad

La interfaz deberá considerar tamaños adecuados de texto, contraste, áreas táctiles y elementos comprensibles para diferentes tipos de usuarios.

## 4.5. Eficiencia

El usuario deberá poder completar las tareas principales utilizando la menor cantidad posible de pasos.

## 4.6. Diseño centrado en el usuario

Las decisiones de diseño se fundamentarán en las necesidades identificadas durante la investigación y serán validadas posteriormente con usuarios reales.

## 9. Validación UX/U

El diseño será validado mediante pruebas con usuarios reales.

Durante la validación se observarán aspectos como:

• Facilidad de navegación.
• Comprensión de los elementos.
• Cantidad de pasos necesarios para realizar una tarea.
• Claridad de los mensajes.
• Facilidad para encontrar información.
• Percepción general de la aplicación.

Los resultados se utilizarán para realizar mejoras al MVP.
