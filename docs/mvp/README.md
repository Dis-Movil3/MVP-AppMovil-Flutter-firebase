# Producto Mínimo Viable (MVP)

---

## 1. Descripción

El Producto Mínimo Viable (MVP) corresponde a la primera versión funcional de la aplicación móvil multiplataforma propuesta para solucionar la problemática de la mala experiencia móvil y los elevados tiempos de carga.

El MVP será desarrollado utilizando Flutter y Firebase, permitiendo ofrecer una solución compatible con dispositivos Android e iOS.

Su propósito principal será validar con usuarios reales si una aplicación móvil optimizada puede mejorar la experiencia de acceso al servicio, reducir los tiempos de espera y facilitar la recepción de información mediante notificaciones push.

---

## 2. Relación con Lean Mobile Development

El MVP constituye un elemento fundamental de la metodología Lean Mobile Development, debido a que permite construir una versión inicial con las funcionalidades esenciales antes de invertir recursos en características secundarias.

El proceso será:

## Construir → Validar → Medir → Aprender → Mejorar.

La primera versión será sometida a pruebas con usuarios reales. Los resultados permitirán determinar qué aspectos funcionan correctamente y cuáles requieren modificaciones.

---

## 3. Problema que busca solucionar

La solución busca atender los siguientes problemas:

• Interfaces no optimizadas para dispositivos móviles.
• Tiempos de carga superiores a 8 segundos.
• Ausencia de notificaciones push en tiempo real.
• Dificultades de navegación.
• Altas tasas de abandono.
• Experiencia poco eficiente desde dispositivos móviles.

---

## 4. Objetivo del MVP

Desarrollar una primera versión funcional de la aplicación que permita comprobar si una experiencia móvil optimizada, respaldada por Flutter y Firebase, puede mejorar el acceso al servicio y reducir las principales dificultades identificadas durante la investigación de usuarios.

---

## 5. Funcionalidades principales

El MVP incluirá inicialmente:

1. Registro de usuarios.
2. Inicio de sesión.
3. Recuperación de contraseña.
4. Pantalla principal.
5. Navegación entre funcionalidades.
6. Consulta de información.
7. Recepción de notificaciones push.
8. Gestión básica del perfil.
9. Cierre de sesión.

## 6. Tecnologías

Flutter	- Desarrollo multiplataforma
Dart	- Lenguaje de programación
Firebase Authentication	- Autenticación
Cloud Firestore	- Almacenamiento de información
Firebase Cloud Messaging	- Notificaciones push
GitHub	- Control de versiones y documentación

---

## 6. Criterios de éxito

El MVP será evaluado teniendo en cuenta los objetivos establecidos para el proyecto:

## Rendimiento

Tiempo de carga inferior a 1.5 segundos.

## Usabilidad

Puntuación SUS superior a 85 puntos.

## Compatibilidad

Funcionamiento en dispositivos:

Android.

## Notificaciones

Recepción de notificaciones push en tiempo real.

Los resultados serán registrados durante la etapa de validación.

---

## 7. Alcance inicial

El MVP se concentrará exclusivamente en las funcionalidades necesarias para validar la solución propuesta.

Las funcionalidades secundarias o de mayor complejidad podrán desarrollarse en iteraciones posteriores si los usuarios manifiestan que aportan valor.

---

## 8. Funcionalidades fuera del MVP

Inicialmente no se priorizarán características como:

• Personalizaciones avanzadas.
• Analítica avanzada.
• Integraciones externas no esenciales.
• Funciones sociales.
• Características que no estén relacionadas directamente con el problema identificado.

Estas funcionalidades podrán evaluarse después de la validación.

---

## 9. Estado

Estado actual: Definición del MVP.

El MVP será actualizado a medida que avance el desarrollo, las pruebas y la validación con usuarios reales.
