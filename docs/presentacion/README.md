# Presentación del Proyecto

---

## 1. Descripción

Esta carpeta contiene los materiales utilizados para presentar el proyecto de desarrollo de una aplicación móvil multiplataforma orientada a solucionar la problemática de mala experiencia móvil y latencia.

La solución propuesta utiliza Flutter para el desarrollo multiplataforma y Firebase para la integración de servicios backend y notificaciones.

---

## 2. Objetivo del proyecto

Diseñar y desarrollar una aplicación móvil multiplataforma utilizando Flutter y Firebase, logrando un tiempo de carga menor a 1.5 segundos en dispositivos Android/iOS y alcanzando una calificación de usabilidad System Usability Scale (SUS) superior a 85 puntos al finalizar el proyecto.

---

## 3. Metodología

El proyecto utiliza la metodología Lean Mobile Development, basada en la creación rápida de un Producto Mínimo Viable (MVP) para posteriormente validarlo con usuarios reales.

El ciclo metodológico utilizado es:

## Investigar → Diseñar → Construir → Medir → Aprender → Mejorar.
