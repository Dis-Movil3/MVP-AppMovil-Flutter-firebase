# Validación del MVP

---

## 1. Introducción

Esta carpeta contiene la documentación correspondiente a la etapa de validación del Producto Mínimo Viable (MVP).

La validación tiene como propósito comprobar, mediante usuarios reales y pruebas técnicas, si la solución desarrollada responde adecuadamente a la problemática planteada.

Esta etapa es fundamental dentro de la metodología Lean Mobile Development, ya que permite obtener evidencia para tomar decisiones sobre futuras iteraciones del producto.

---

## 2. Objetivos a validar

Evaluar el funcionamiento, rendimiento y usabilidad del MVP mediante pruebas con usuarios reales y mediciones técnicas, con el propósito de determinar si se cumplen los objetivos establecidos para el proyecto.

---

## 3. Objetivos a validar

Se establecen dos indicadores principales:

## Rendimiento

El tiempo de carga inicial de la aplicación deberá ser:

Menor a 1.5 segundos.

## Usabilidad

La aplicación deberá alcanzar una puntuación:

SUS superior a 85 puntos.

---

## 4. Metodología de validación

La validación se realizará mediante dos enfoques complementarios:

## Validación con usuarios

Permitirá observar la interacción de los usuarios con la aplicación y conocer su percepción sobre:

Facilidad de uso.
Navegación.
Claridad de la interfaz.
Comprensión de las funcionalidades.
Experiencia general.
Validación técnica

Permitirá medir:

Tiempo de carga.
Tiempo de respuesta.
Funcionamiento de las notificaciones.
Comportamiento en diferentes dispositivos.
Funcionamiento en Android e iOS.

---

## 5. Funcionalidades principales

El MVP incluirá inicialmente:

1. Registro de usuarios.
2. Inicio de sesión.
3. Recuperación de contraseña.
4. Pantalla principal.
5. Navegación entre funcionalidades.
6. Consulta de información.
7. Recepción de notificaciones push.
8. Gestión básica del perfil.
9. Cierre de sesión.

## 6. Tecnologías

Flutter	- Desarrollo multiplataforma
Dart	- Lenguaje de programación
Firebase Authentication	- Autenticación
Cloud Firestore	- Almacenamiento de información
Firebase Cloud Messaging	- Notificaciones push
GitHub	- Control de versiones y documentación

---

## 7. Criterios de éxito

El MVP será evaluado teniendo en cuenta los objetivos establecidos para el proyecto:

## Rendimiento

Tiempo de carga inferior a 1.5 segundos.

## Usabilidad

Puntuación SUS superior a 85 puntos.

## Compatibilidad

Funcionamiento en dispositivos:

Android.

## Notificaciones

Recepción de notificaciones push en tiempo real.

Los resultados serán registrados durante la etapa de validación.

---

## 8. Alcance inicial

El MVP se concentrará exclusivamente en las funcionalidades necesarias para validar la solución propuesta.

Las funcionalidades secundarias o de mayor complejidad podrán desarrollarse en iteraciones posteriores si los usuarios manifiestan que aportan valor.
